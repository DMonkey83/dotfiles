# dotfiles

EndeavourOS + Hyprland (JaKooLit Hyprland-Dots, Lua config) + zsh/p10k + LazyVim, kitty, ghostty.
Packages go through **paru**, Rust through **rustup**, Node through **nvm**.

```
install.sh          one-shot setup for a fresh install
scripts/
  packages.sh       paru bootstrap, repo + AUR packages, services, zsh as login shell
  configs.sh        copy config/ and home/ into place (backs up what it overwrites)
  dev.sh            rustup + cargo tools, zgen, nvm/Node/npm globals, bun, Claude Code, LazyVim plugins
  sync.sh           copy THIS machine's configs + package lists back into the repo
  extras.sh         export/import wallpapers, icons, themes (too big for git)
config/             mirrors ~/.config/<name>   (list in scripts/lib.sh)
home/               mirrors ~                  (.zshrc .zshenv .p10k.zsh .gitconfig)
packages/
  repo.txt aur.txt  generated by sync.sh from `pacman -Qqen` / `pacman -Qqem`
  extra.txt         hand-maintained additions (repo or AUR)
  amd.txt           AMD GPU packages, installed only if lspci shows an AMD GPU
  system.txt        kernel/boot/firmware - reference only, never installed
  services.txt      systemd services to enable
  cargo.txt node.txt npm.txt   generated by sync.sh
```

Configs are **copied**, not symlinked: the JaKooLit scripts and wallust rewrite
files in `~/.config` all the time, and symlinks would make the repo permanently
dirty. Edit live files as usual and run `scripts/sync.sh` when you want to save them.

## Old PC: before switching

```bash
scripts/sync.sh                                   # refresh configs + package lists
git add -A && git commit -m "sync" && git push
scripts/extras.sh export /run/media/$USER/<usb>   # wallpapers, icons, themes (~1.6 GB)
```

Also copy by hand (not in git on purpose): `~/.ssh` (needed for the `git@github.com`
remote), `~/.gnupg` if you sign anything, and anything under `~/.local/share/godot`
or `~/.local/bin` you want to keep (own builds: listapp, calisthenics-trainer).

## New PC

1. Install EndeavourOS (any desktop - Hyprland comes from the package list).
   Plain Arch works too: paru is built from the AUR and the EndeavourOS-only
   packages are reported and skipped.
2. Clone and run:
   ```bash
   git clone https://github.com/DMonkey83/dotfiles.git ~/dotfiles
   cd ~/dotfiles
   ./install.sh        # or ./install.sh -y to skip paru prompts and AUR review
   scripts/extras.sh import /run/media/$USER/<usb>
   ```
3. Log out, choose the Hyprland session. On the first login
   `~/.config/hypr/initial-boot.sh` applies the GTK/icon/cursor/Kvantum themes.
4. Open a terminal once - zgen downloads the zsh plugins and powerlevel10k.

Every step is safe to re-run, and can be run alone: `./install.sh configs`,
`./install.sh dev`, `scripts/packages.sh -y`, ...

## Things to check by hand

- **Monitors** - `config/hypr/hyprland.lua` hardcodes `HDMI-A-1` (Samsung 4K, must stay
  `@30`) and `DP-2` (4K), plus the workspace-to-monitor rules right below them.
  Output names can change with a different GPU: run `hyprctl monitors` and adjust.
- **Extra drives** - if the disks move to the new PC, add them to `/etc/fstab`:
  ```
  UUID=39022988-52cb-45db-b2d2-2c4380579543 /mnt/games ext4 defaults,noatime 0 2
  UUID=032b3861-bc3c-4020-ba45-5b798c0d14e1 /mnt/dev   ext4 defaults,noatime 0 2
  ```
  `abacus` (bound to `SUPER+C`) is built from `/mnt/dev/Projects/abacus`; `scripts/dev.sh`
  skips it until that path exists, so re-run `./install.sh dev` after mounting.
- **multilib** - steam and `lib32-*` need `[multilib]` enabled in `/etc/pacman.conf`
  (EndeavourOS enables it by default).
- **exa** is unmaintained and may fail to build with a new Rust; `eza` (repo package)
  is a drop-in replacement for the `lx` alias.
- **Username** - `.zshrc` hardcodes `/home/evilnis` in the pnpm, bun and `~/.local/bin`
  PATH lines; keep the same username or search-and-replace.
